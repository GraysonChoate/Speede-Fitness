# Navigation Control Rail

Use `nav-control-rail-reference.png` as the visual target.

## Structure

- Keep the header full-width and compact.
- Use an optical-black translucent surface over the hero media.
- Add a fine graphite grain at low opacity.
- Keep the Speede logo static and unchanged.
- Replace the `COMING SOON` pill with a bracketed status marker and one restrained lime node.
- Use these labels: `Force`, `How it adapts`, `The machine`, `Athletes`.
- Use `See it first` for the command button.

## Active State

- Active text changes from graphite gray to off-white.
- A 2px lime rail appears beneath the active label.
- One 4-5px node sits at the rail's leading edge.
- On scroll, move the rail and node to the next destination over 280-360ms using a restrained ease.

## Hover

- Inactive label rises from approximately 58% to 90% text opacity.
- Draw a 1px underline outward from the label center over 180-220ms.
- Do not move or scale the label.

## CTA

- Use an 8px corner radius, not a pill.
- Add a small arrow icon.
- On hover, shift the arrow 3px right and brighten the inset border.
- Do not scale the button.

## Surface

- Backdrop blur: 14-18px.
- Black surface opacity: 86-94%.
- Grain opacity: 8-14%.
- Bottom calibration rail: 20-36% opacity.
- The underlying hero should remain barely visible through the header.

## Reduced Motion

- Render the correct active state immediately.
- Disable rail travel and arrow translation.
